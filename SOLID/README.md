# SOLID Principles

| Letter | Principle | Short idea |
|---|---|---|
| **S** | Single Responsibility | One class - one responsibility |
| **O** | Open/Closed | Open for extension, closed for modification |
| **L** | Liskov Substitution | Child must be substitutable for Parent |
| **I** | Interface Segregation | Don't force classes to depend on methods they don't need |
| **D** | Dependency Inversion | Depend on abstractions, not concrete implementations |

Every folder contains:

* `before.cpp` - code that violates the principle
* `after.cpp` - the same code, fixed
* `README.md` - explanation
